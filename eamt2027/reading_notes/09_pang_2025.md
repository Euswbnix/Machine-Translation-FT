  1. Terminology mismatch:Medical 领域的 Folienverpackung(foil package)被其他领域微调模型错误翻译为 slide pack、sterile packaging 或 slide wraps。

  **关键限制:** 没有针对每个术语进行微调前后的配对正确性检查;没有统计原本正确、微调后错误的术语比例;没有独立区分 beneficial vocabulary shift 和 detrimental vocabulary shift;没有绘制术语遗忘随 optimizer updates 变化的曲线;没有通过控制实验区分知识遗忘、输出词汇偏移和一般领域不匹配。

  因此,该论文提供的是与术语遗忘相一致的行为证据,而非对遗忘机制的严格量化验证。

- [x] **是否给出微调数据的什么属性导致遗忘?与词表覆盖有没有关系?**

  **没有直接建立微调数据的 vocabulary coverage 与遗忘程度之间的关系。**

  **(1)领域分布及术语偏移:Section 3.1**

  - 单领域微调使模型偏向该领域的术语和表达方式。跨领域错误案例表明,训练语料中的词汇偏好可能影响模型在其他上下文中的词汇选择。
  - 但作者没有测量各领域微调语料的 target vocabulary coverage、unique token types、词频分布或词汇分布距离;也没有构造词汇覆盖相同但上下文不同的训练子集。
  - 因此,领域词汇偏移是观察到的现象,词表覆盖不足是否为其原因并未得到验证。

  **(2)平行数据规模:Section 3.2**

  作者从 WMT23 德英语料中随机抽取不同规模的平行数据,比较 SFT 和 CPT-SFT。

  - Llama2-7B 在使用 100K 平行句对时取得最佳结果:41.6 BLEU、83.9 COMET-DA。继续增加至数百万句对时,两种训练方式均出现性能下降。
  - Llama2-13B 在更小的数据规模下达到最佳表现:10K 43.6 BLEU;100K 42.5;10M 40.0(从 10K 到 10M 下降 3.6)。
  - 作者推测,过量平行语料可能干扰 LLM 在预训练阶段已经获得的双语知识。但这一解释没有通过直接知识保留指标进行验证。
  - 由于主要训练设置为固定 3 epochs,数据规模增加通常也意味着更多 optimizer updates 和训练 token exposure。因此,不能排除训练长度、过度微调或学习率调度造成的影响。
  - 作者没有通过固定更新步数、匹配累计训练 tokens 或学习率消融,独立验证数据规模本身的影响。

  **(3)低频词翻译:Section 3.3、Appendix A.4**

  作者使用完整 WMT23 德英语料(295,805,439 句对)计算源端词汇出现频率,并使用 FastAlign 进行词对齐,评估不同频率区间的词汇翻译 precision 和 deletion rate。

  - 该实验使用的是 source-side word frequency,而不是微调语料的 target-side vocabulary coverage。
  - LLM 对高频词表现较好,但仍可能错误翻译或省略低频词。这说明预训练 LLM 没有完全解决 rare word translation 问题。
  - 但低频词翻译错误不等同于微调后遗忘,因为实验没有逐词比较微调前后的正确性。

  正式记录:**Pang et al. identified domain-dependent terminology errors, performance degradation with excessive parallel training data, and difficulties in rare-word prediction. However, they did not establish adaptation-set vocabulary coverage as a causal determinant of forgetting.**

  来源:Sections 3.1–3.3,Tables 2–4,Figures 1–3,Appendix A.4。

  **是否改变过学习率?**

  - 不同训练阶段使用不同学习率:CPT 为 3e-4,SFT 为 2e-5。但这属于不同训练阶段的超参数配置,不是针对同一种微调方式进行的 learning-rate ablation。

Saunders & DeNeefe 在 Limitations, p. 12668 中明确表示:他们自己的实验仅涉及中等规模的 encoder-decoder NMT Transformers;Pang et al. 使用相同的 De→En OPUS 多领域数据集,发现 LLM 也存在类似领域术语遗忘的行为,具体表现为模型偏向 adaptation set 中出现的词汇,而不能正确使用其他领域的术语;Pang et al. 没有进一步解释或缓解该现象;Saunders & DeNeefe 将在 LLM 上验证自身研究结论列为未来工作。

**对我们 LoRA 实验设计的意义**

在进行 COMET-KIWI 筛选后的 LLM LoRA fine-tuning 时,必须区分三个问题:QE-based filtering 是否降低了训练数据的词汇覆盖及上下文多样性;受限的训练数据分布是否使模型产生有害的目标词汇偏移;性能下降是否实际上来自过高的学习率、过多的训练步数或过度微调。

**建议的 LoRA 主实验配置(本文拟采用的设计,不是 Pang et al. 原文设置):**

| Parameter | Suggested configuration |
|---|---|
| Fine-tuning method | LoRA |
| Main learning rate | 2e-5 |
| LR sensitivity analysis | 1e-5, 2e-5, 1e-4 |
| LoRA rank | 16 |
| LoRA alpha | 32 |
| LoRA dropout | 0.05 |
| LoRA target modules | Fixed across all groups |
| Training budget | Matched optimizer updates and token exposure where feasible |
| LR scheduler | Same across groups |
| Random seeds | At least 3 |
| Initial checkpoint | Identical pretrained model |
| Evaluation checkpoints | Step 0 and matched intermediate/final checkpoints |

- 2e-5 可以作为与 Pang et al. 对照的保守起始学习率,但不是经过验证的 LoRA 最优学习率。不能直接将全参数微调的最优学习率推广到 LoRA。
- 如果计算预算有限,优先对 Random 和 QE Top-k 两组进行 learning-rate sensitivity analysis,再固定学习率进行主要机制实验。
- 冻结 base model 参数不代表 LoRA 不会导致行为层面的遗忘;启用 adapter 后的模型仍可能出现输出分布偏移。
- 建议同时评估禁用 adapter 的原始模型,以明确观察到的退化来自 adapter-induced behavioral change,而不是 base weights 被覆盖。

**建议的术语遗忘指标**

设 M₀ 为微调前模型,Mₜ 为经过 t 次更新的模型,C₀ 为微调前正确翻译的测试术语实例集合。Forgetting Rate(t) = |{x ∈ C₀ : Mₜ incorrectly translates x}| / |C₀|,即微调前能够正确翻译、微调后不再正确翻译的术语实例比例。

同时报告:BLEU、chrF++、COMET;target vocabulary coverage;forgotten-term rate;acquired-term rate;out-of-domain degradation;source/target n-gram novelty;unigram frequency distribution divergence。

建议根据测试目标词汇在微调数据中的出现情况分组:Unseen(频率 0)、Rare(低频)、Frequent(高频)。

重点检验:

1. QE Top-k 是否比 Random 遗忘更多微调前已掌握的术语。
2. 未被微调语料覆盖的目标词汇是否具有更高的遗忘概率。
3. 在 unigram coverage 相近时,窄词表多样组是否比重复组保留更多原有翻译能力。
4. 降低学习率是否能够消除 QE Top-k 与 Random 之间的差距。
5. 在匹配训练预算后,性能差距是否仍然存在。

具体学习率、LoRA rank 及训练预算仍需根据所选模型和预实验结果确定。

**对本文创新性的影响**

- 不能声称此前没有研究观察到 LLM 微调后的术语遗忘;不能声称此前没有研究发现增加平行数据可能损害 LLM 翻译性能。
- Saunders & DeNeefe 已经研究了传统 NMT adaptation 中词汇覆盖与遗忘的关系。Pang et al. 已经观察到 decoder-only LLM 的领域术语错误,但没有直接验证词汇覆盖是否导致遗忘。
- 两篇论文均未通过 QE-based selection 构造受限词汇分布,并在 LoRA fine-tuning 下控制训练预算、词汇覆盖和上下文多样性。
- 因此,我们的潜在贡献是检验 QE-induced lexical restriction 是否能够导致 LLM 的翻译能力退化,并进一步解耦 lexical coverage、contextual diversity 和 repeated exposure 的作用。
- 如果加入微调前后的术语级配对分析,就可以进一步判断观察到的性能下降究竟是无法学习新知识,还是已经掌握的翻译知识发生行为层面的遗忘。

**Related Work 英文表述(草稿)**

Pang et al. (2025) observed domain-specific terminology errors and vocabulary shifts in fine-tuned Llama2 translation models, indicating that pretrained decoder-only LLMs remain susceptible to domain mismatch. Saunders and DeNeefe (2024) independently linked catastrophic forgetting in conventional NMT adaptation to target-side vocabulary coverage and identified the observations of Pang et al. as evidence of analogous behavior in LLMs. However, Pang et al. did not explicitly quantify pre-to-post fine-tuning terminology forgetting or investigate adaptation-set vocabulary coverage as a causal factor. Their experiments also did not include a LoRA-specific forgetting analysis or a controlled learning-rate sensitivity study. Our experiments extend this line of research by examining whether quality-based data selection induces lexical and contextual restrictions that contribute to behavioral forgetting during parameter-efficient fine-tuning.

## Claude 的补充(2026-11-27)

1. **你建议的配置和 E1.0 预注册草稿的现有设计有三处不同,建议以草稿为底、把你的两个想法加进去。** 草稿现在是:
   - LoRA:所有线性层,r = 64,alpha = 32;一个 epoch(1,676 步,有效批大小 128);5 个种子;
   - 学习率:第一阶段只在随机组上从 1e-4、2e-4、4e-4 里挑(只看 FLORES+ dev),挑完冻结;
   - 另有全参数微调一臂:学习率 2e-5,重复 / 多样各 3 个种子;
   - 检查点在 25%、50%、100%。
   你建议 LoRA 主学习率用 2e-5。问题是 2e-5 是全参数微调的量级(Pang、Tan 都是全参数或未说明),LoRA 的常用量级是 1e-4 到 4e-4(Fujita de Mello 用 2e-4)。LoRA 用 2e-5 很可能训不动,到时"没差距"会分不清是没效应还是没学到。草稿的安排已经同时覆盖了两类文献:全参数臂的 2e-5 对上 Pang 和 Tan,LoRA 网格里的 2e-4 对上 Fujita de Mello。秩的选择(16 还是 64)是待定决定,可以在定 E1.0 时一起定;草稿选 64 的理由是让 LoRA 尽量接近全参数微调。
2. **你提的第 4 个检验(降低学习率能不能消除差距)是草稿里缺的,值得加。** 现在的草稿只在随机组上挑学习率,然后只在一个学习率下比较重复和多样。可以加一小臂:在另外两个没被选中的学习率下,重复和多样各跑 1–3 个种子。每次 LoRA 约 1.4 GPU·时,加 4–12 次,约 6–17 GPU·时。这样 LLM 臂自己就能回答"效应是否依赖学习率",和 NMT 臂的学习率对照(E0.6-LR)互相印证。这是一项新的待定决定,要在跑之前登记。
3. **你定义的 Forgetting Rate 和我们已经实现的 ForgetGenUse 是同一类量。** 第 6 项(`phase0/next/cpu_items/item6_forgetting/`)按 Saunders & DeNeefe 的 Eq 1 算的就是"底座译对、微调后译错"的次数,分母是参考译文里的出现次数;"acquired"对应脚本里已经输出的 gained;你的 Unseen / Rare / Frequent 分组是对现有 ID / OOD 两分的细化(加频率档是小改动)。所以 E1.0 不需要新指标,直接复用这个脚本,并在预注册里登记(草稿第 11 项已提到在 E0.6 输出上算它;LLM 臂要补一句:底座译文用什么提示得到)。
4. **"第 0 步"的评测要定清楚用哪种底座输出。** Qwen3-1.7B-Base 是纯续写模型,不给示例就翻不好;草稿的试跑门槛用的是 8-shot。所以"微调前的模型"有两种:零样本和 8-shot。ForgetGenUse 里的底座译文用哪一种,结果会很不一样。建议用 8-shot 的输出作底座(那才是模型"会"的水平),并写进预注册。
5. **"禁用 adapter 再评一次"不需要单独做。** LoRA 不改底座权重,禁用 adapter 的模型就是微调前的模型,和第 0 步是同一个评测,一次就够。你的提醒本身是对的:LoRA 的退化是行为层面的,论文里用词要写"行为上的遗忘",不要写成权重被覆盖。
6. **Pang 的"数据越多越差"对我们集合大小的含义。** 他们的 7B 模型 10 万句最好,13B 模型 1 万句最好(各训 3 个 epoch,训练量没对齐)。E1.0 每组 214,489 句、训 1 个 epoch,落在他们"开始下降"的区间附近。这不影响组间比较(各组句数相同),但提示绝对分数可能不如更小的集合;草稿的 25%、50% 检查点正好能看出有没有"训多了反而差"。
7. **Related Work 草稿。** 前三句准确。最后一句"examining whether quality-based data selection induces lexical and contextual restrictions that contribute to behavioral forgetting during parameter-efficient fine-tuning"比 E1.0 实际能回答的宽:E1.0 比的是重复 / 多样 / 随机三组在 LLM 上的差距,不单独操纵覆盖。建议等 E0.6 和 E1.0 的结果出来再定这句。另外引用用 TACL 2025 的正式版。
